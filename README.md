# Analisis POS offline-first

Vault de Obsidian para documentar el analisis incremental de un sistema de punto de venta y comandas con dispositivos moviles offline-first.

Entrada recomendada: [[00 - Inicio/Mapa del vault|Mapa del vault]]

Objetivo del vault:

- Mantener decisiones tomadas y pendientes.
- Documentar los modos de operacion `standalone` y `server_sync`.
- Documentar el modelo de sincronizacion offline-first.
- Documentar la paridad operativa offline: toda operacion online debe poder registrarse offline salvo imposibilidad externa.
- Servir como fuente de verdad para desarrollo.
- Registrar cambios de criterio conforme avance el proyecto.

Estado inicial del analisis: en construccion.
